Giải thích

Dùng clear:left/right/both để phần tử tiếp theo không bị ảnh hưởng bởi float trước đó. Quan sát trực tiếp vùng minh họa để nhận biết cách thuộc tính CSS tác động đến vị trí, kích thước, luồng hiển thị hoặc hiệu ứng của phần tử. Hãy thay đổi kích thước trình duyệt để kiểm tra khả năng thích ứng khi có media query.

Mã CSS trọng tâm

.float-box{float:left;background:#bfdbfe;padding:22px;margin:0 10px 8px 0}.clear-box{clear:both;background:#bbf7d0;padding:14px;border-radius:8px}
