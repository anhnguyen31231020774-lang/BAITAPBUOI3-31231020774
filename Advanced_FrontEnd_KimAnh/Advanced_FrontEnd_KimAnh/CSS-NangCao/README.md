1. **E-commerce:** tích hợp xZoom, Bootstrap Progress, nhãn giảm giá/New/Best Seller và Bootstrap Star Rating.
2. **jQuery LMS:** dựa vào `.modtype_assign` và `.instancename` để tìm bài thứ 5; duyệt section để liệt kê chủ đề, assignment và thông tin deadline.

## Lưu ý về LMS
Dữ liệu trong phần hiển thị mẫu là dữ liệu minh họa. Để lấy dữ liệu thật, đăng nhập LMS, mở đúng trang khóa học và chạy đoạn jQuery trong Console. Selector section/deadline có thể cần điều chỉnh theo cấu trúc DOM thực tế của LMS.
