## Nội dung
- **Lab 07:** CSS Advanced với 19 Exercise về document flow, positioning, float, responsive, transform, transition, filters, animation và Bootstrap.\n- **Lab 08:** JavaScript nhúng/ngoài, Console, String, Date, Math, Array, Function, Object và mảng đối tượng.
- **Lab 09:** DOM selection, quan hệ DOM, tạo/xóa phần tử, event listeners, load events, debugging, form focus/blur và validation.
- **Lab 10:** jQuery setup, selectors, listeners, DOM insertion, animations, GET requests và jqXHR handling.

## Triển khai GitHub Pages
1. Sao chép thư mục `JavaScript-Labs` vào repository hiện có của học phần; không tạo repository mới và không xóa bài cũ.
2. Commit và push toàn bộ mã nguồn.
3. Đặt repository ở chế độ Public.
4. Vào **Settings → Pages**, chọn nhánh `main` và thư mục `/ (root)` (hoặc cấu hình Pages hiện tại của repository).
5. Sau khi GitHub Pages triển khai xong, truy cập `.../JavaScript-Labs/`.
